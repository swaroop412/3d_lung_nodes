System Information

🧠 3D CNN Architecture

This system utilizes a custom ResNet-style 3D Convolutional Neural Network trained on volumetric CT data to identify pulmonary nodules with high precision. It processes the full spatial context of the scan.

🔍 Explainable AI (XAI)

Integrated Grad-CAM technology provides visual transparency, highlighting the exact voxels influencing the model's prediction across Axial, Coronal, and Sagittal planes.

🛡️ Privacy & Security

All processing is performed locally on the secure inference server. Uploaded NIfTI scans are processed in memory and are not permanently stored, ensuring patient data privacy.
